# Pengembangan pembacaan CV HR

Pada mode demo, PDF dan DOCX diproses di browser. Email tunggal dapat diusulkan ke formulir, sementara HR meninjau dan melengkapi data lain. File tidak disimpan atau dikirim.

Untuk integrasi AI berikutnya, tambahkan layanan backend yang menerima teks hasil ekstraksi setelah persetujuan pengguna, mengembalikan kandidat nilai terstruktur dengan validasi, dan menampilkan setiap usulan untuk ditinjau sebelum disimpan. Tentukan kebijakan penyimpanan dan penghapusan dokumen, batas akses, serta penanganan file hasil pindai sebelum integrasi tersebut digunakan.
